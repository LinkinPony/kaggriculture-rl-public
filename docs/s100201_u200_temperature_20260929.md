# s100201 U200: Turn=0 / Turn=1 Local Win Rate Comparison

After completing a Kaggle submission and temperature evaluation for the latest s100901 U480, the user requested an evaluation of the difference between T=0 and T=1 for v5b s100201 U200. This evaluation is conducted locally only.

## Frozen Weights and Protocol

- Run: `derived-v5b-m384-dsmclone-ppo50-warmup300-20260929-s100201`.
- Members: `checkpoints/update-000200.pt`.
- SHA256: `339858dec21087d07ae8dc627f2ab6dc9bb2828f20f62c910eb5338d14eb1b9d`,
  matches the submitted **56671443**.
- Configuration: `configs/evaluation_panel_s100201_temperature.yaml`.
- FP32 CUDA, full 384 turn memory; candidate T=0/T=1, opponent fixed at T=1.
- Each panel has 64 shared environment seeds per opponent, with seat swapping, totaling 128 games; eight opponents equally weighted,
  1,024 games per temperature, totaling 2,048 games.
- Reuses seven opponents from [U480 panel](s100901_u480_temperature_20260929.md): MMPQ, DSM,
  Vadim, DECEM, Tufa clone, s99001 U200, and the current s100901 BC starting point; replaces the original s100201's opponent position with s100901 U480 (T=1).
  The weights and seeds for the seven shared opponents remain unchanged.
- Additionally uses 64 independent environment seeds for seat swapping, completing 128 games of direct T=0/T=1 matchups with equal weights.

All inputs and source code are frozen at `outputs/analysis/s100201-u0200-temperature-20260929/`.
351 actor tensor bits are bitwise identical and finite across two temperature settings; 153 strategy source code files and native environments match the s100201 training archive. The model tensors of seven common opponents are also bitwise identical to the U480 panel, see [Input Verification](../outputs/analysis/s100201-u0200-temperature-20260929/input-verification.json).
Three panel processes per GPU, each with 4% of VRAM limit; four direct combat batches each have a 2.5% limit.
Both supervisors halt their evaluation processes when any GPU's idle VRAM falls below 12 GiB.

Win rate intervals are clustered by environment seed, preserving the correlation between exchange seats and common opponents. Cloning belongs to local agents;
This is not the overall win rate of Kaggle opponents. The eight-opponent panel differs from the U480 panel by one opponent, and thus cannot directly use total scores to determine which weight is stronger.
